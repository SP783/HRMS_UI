How it works

{{ site_name }} connects to your existing activity tracker database as a read-only secondary connection. No data is written to it.

Employees are matched to workstation records using the hostname field in the Employee Directory. Assign a hostname to each employee so their activity data appears here.

{{ site_name }} expects a table named activity_summary with columns: hostname, last_seen, active_seconds, idle_seconds, top_application, status.

Server requirements: PostgreSQL needs pip install psycopg2-binary on the {{ site_name }} server. MySQL needs pip install mysqlclient. SQLite works out of the box.
